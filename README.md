# DJ-котик: выбор цветов

Страница, на которой покупатель выбирает цвета для печати котика в наушниках: готовые расцветки, цвет каждой детали и вращение на 360°.

Внутри только отрендеренные кадры (`frames/`: освещение в `ds*.webp`, карты деталей в `id*.png`) и код страницы, файлов 3D-модели здесь нет. Цвет считается в браузере: `цвет детали × освещение + блик`.
