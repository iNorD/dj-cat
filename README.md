# DJ-котик: выбор цветов

Страница, на которой покупатель выбирает цвета для печати котика в наушниках: готовые расцветки, цвет каждой детали и вращение на 360°.

Внутри только отрендеренные кадры и код страницы, файлов 3D-модели здесь нет. Цвет считается в браузере: `цвет детали × освещение + блик`.

Кадры лежат в `turn/`, 120 штук, через каждые 3°. В `ds*.webp` освещение: сверху рассеянный свет, снизу блик. В `ip*.png` карта деталей 1440×1800 с номерами деталей по два в байте: левая из пары в старших четырёх битах.
